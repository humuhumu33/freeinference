Free verified AI inference.

Runs open models on your own machine. No account, no key, no price per token.

Every answer carries a receipt that any machine can replay.

A prompt you repeat costs nothing the second time.

Install

curl https://humuhumu33.github.io/freeinference/install | sh

Change one line

from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:11435/v1", api_key="local")

reply = client.chat.completions.create(
    model="qwen3:8b",
    messages=[{"role": "user", "content": "Hello"}],
)
print(reply.system_fingerprint)

Three proofs

  1. The model you load matches the hash its publisher shipped. Run hologram verify and read one line.
  2. The answer you get replays byte for byte on any machine. The receipt names the model, the prompt and the settings.
  3. The prompt you send twice is served from work already done. The usage field says how much.
