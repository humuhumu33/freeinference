# freeinference

**Free verified AI inference.**

A local, OpenAI compatible endpoint that runs open models on your own machine at no price per token. Every answer carries a receipt any machine can replay to confirm or refute it. Prompts you repeat become free, because computed work is content addressed and reused.

Homepage: https://humuhumu33.github.io/freeinference/

## Status

Phase 0 and Phase 1 of the plan in `PLAN.md`.

- Phase 0, homepage: shipped from `site/`, gated by `scripts/check_site.py`.
- Phase 1, endpoint with receipts: `freeinference serve` exposes `/v1/chat/completions` and `/v1/models`. When the requested model resolves in the local catalog, `system_fingerprint` is the model κ joined with the engine κ, and the `x-hologram-receipt` header names a stored, signed receipt. When it does not resolve, neither is present.

Later phases: verify, prefix cache, verified pull, catalog and Anthropic protocol, desktop, sharing.

## Build and run

```bash
cargo build --locked
cargo run --locked -- serve
```

Then point any OpenAI client at `http://127.0.0.1:11435/v1`.

## How it is built

- Daemon, module system, router, OpenAPI, CLI, config, audit log and BDD harness come from `hologram-live`, depended on by git revision, never forked. The only upstream change is a ten line seam that lets a downstream binary register modules.
- κ addressing comes from `uor-hologram`.
- OpenAI request validation uses `async-openai` types.
- Receipts are signed with Ed25519.

One capability equals one module, one config section, one conformance suite, one feature file, one directory. Removing a capability means deleting its directory and one registration line.

## Governance

`model/ids.toml` holds every claim. Each claim has exactly one scenario under `features/suites/` and exactly one test named `conformance_<id>`. `CONFORMANCE.md` is generated by `just model-write` and never edited. `just vv` is the only definition of green. The full PrismPM template, with its pinned devcontainer and digest bound action, is adopted in a following step; the claim ledger and bijection are enforced from the first commit.
